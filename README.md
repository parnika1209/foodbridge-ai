# FoodBridge AI — Working Front-End Prototype

FoodBridge AI is a demonstration platform for connecting surplus-food donors with NGOs and community organisations. It supports SDG 2 (Zero Hunger) and SDG 12 (Responsible Consumption and Production).

## Run the prototype
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add a sample food listing.
4. Click **Request pickup** on an available listing.
5. Use the filter to view available or requested listings.

No installation or API key is required.

## Prototype features
- Add a surplus-food listing.
- Display donor, food, quantity, location and collection deadline.
- Request a pickup and update the listing status.
- Filter available and requested listings.
- Dashboard counters update during the session.

## Limitations
This is a front-end demonstration. Data is held in browser memory and resets when the page is refreshed. It does not have accounts, a backend database, live maps, real NGO verification, or an AI model. Do not use it to coordinate real food donations without adding secure storage, verified partners, and food-safety procedures.

## Suggested next steps
- Add a Python Flask backend and database.
- Add verified donor and recipient accounts.
- Add map-based matching and pickup notifications.
- Test with local NGOs and food-safety partners.
